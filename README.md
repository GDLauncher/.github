# 🚀 GDLauncher

GDLauncher is a **Minecraft launcher** built on **instances**. Each instance holds its own mods, world, and **Java** settings, and modpacks install into a fresh folder.

- 📦 **Modpack installs** with versions
- ⚙️ **Per-instance Java** arguments
- 🧩 **Mod management** between instances
- 💾 **World isolation**
- 🔄 **Instance cloning**

- 🖥️ **Skin and account handling**

## 🚀 Why Choose GDLauncher?

Instances keep a heavily modded pack away from a vanilla world. Cloning duplicates a working setup instead of rebuilding it file by file.

Java arguments live per instance, so a heavy pack can use different memory than a light one.

## 🎮 Why Use It?
